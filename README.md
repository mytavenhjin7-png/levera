# LEVERA — Multi Brand Store

Улаанбаатарын олон брэндийн онлайн бутик: **вэбсайт + backend API + SQLite database + админ самбар**.
30 брэнд × 40 бараа = **1,200 бараа**. Үнэ бүрт **барааны үнэ + карго (Эрээн → УБ) + LEVERA үйлчилгээ** багтана.
Монгол / англи хэлтэй. QPay төлбөр, Telegram мэдэгдэл, AI чат багтсан.

## 1. Ажиллуулах

Node.js **22.5 ба түүнээс шинэ** хэрэгтэй (database нь Node-ийн дотоод `node:sqlite`, нэмэлт package шаардахгүй).

```bash
npm start
```

- Сайт: http://localhost:8787
- Дэлгүүр: http://localhost:8787/shop.html
- Админ: http://localhost:8787/admin.html — нууц үг (token) серверийг асаахад terminal дээр гарна, мөн `data/admin-token.txt` файлд хадгалагдана.

Анх асаахад `data/levera.db` үүсч, 1,200 бараа автоматаар орно. Сервер асахдаа болон 6 цаг тутам каргоны өнөөдрийн тарифыг шинэчилж, өөрчлөгдвөл бүх үнийг дахин бодно.

> `index.html`-ийг шууд давхар товшиж (file://) нээвэл ажиллахгүй. Заавал `npm start`-аар нээнэ.

## 2. Үнэ хэрхэн бодогддог

```
Үнэ = Барааны үнэ ¥ × ханш  +  үйлчилгээ %  +  карго  (+ Хятад дотоод хүргэлт, + УБ хүргэлт)
      → 1,000₮ хүртэл дээш бүхэлдэнэ
```

Каргоны үнэ (`server/cargo.mjs`):

- жинг 0.5 кг хүртэл дээш бүхэлдэж × ₮/кг (одоо **3,000₮/кг**)
- эзлэхүүн (м³) × ¥/м³ (одоо **¥599/м³**, Эрээн → Цирк салбар), юанийг дээш бүхэлдэж × тохируулсан ханш (одоо **¥1 = 545₮**)
- аль их нь тооцогдоно (0.01 м³-ээс бага бол жингээр)

Бараа бүр савласан жин ба хайрцгийн хэмжээтэй (жишээ нь пүүз 1.6 кг, 36×24×14 см → 6,000₮; хөвөнтэй куртка 50×40×20 см → овроор 13,100₮).
Барааны хуудсан дээр үйлчлүүлэгч бүх задаргааг харна.

**Үнийн томьёо** (`server/cargo.mjs` → `priceProduct`):

| | Томьёо |
|---|---|
| Ихэнх бараа | Dewu ¥ × ханш (₮541) + **үйлчилгээний шимтгэл** + HiCargo карго + **UBCab хүргэлт ₮6,000** |
| Шимтгэл | Барааны үнийн эхний ₮2,000,000 хүртэлх хэсэгт **20%**, түүнээс дээш хэсэгт **15%**, хамгийн багадаа **₮15,000** |
| Сүрчиг, гоо сайхан | Албан ёсны үнэ $ × ханш (₮3,608) + **гааль 5%** + **НӨАТ 10%** + UBCab хүргэлт (Улаанбаатарын албан ёсны сүрчгийн дэлгүүрийн түвшин). Dewu-ийн өртөг + шимтгэлээс доош хэзээ ч бууруулахгүй. |

Жишээ: Dior Sauvage EDP 100 ml = $140 → ₮590,000 (өртөг ~₮420,000, ашиг ~₮170,000). Uniqlo HEATTECH ¥99 → ₮77,000. LV Neverfull MM ¥15,200 → ₮9,570,000.

Админ → **Карго ба үнэ** хэсэгт бүх хувь, ханш, хүргэлтийн үнийг өөрчилнө. Хадгалахад бүх барааны үнэ дахин бодогдоно. Мөн тэнд карго тооцоолуур бий. Сүрчгийн албан ёсны үнийг Админ → Бараа → «$ албан» талбарт, эсвэл `tools/fragrance-retail.mjs` хүснэгтэд засаад `node tools/fragrance-retail.mjs`.

## 3. Барааны мэдээлэл ба зураг — ЗААВАЛ УНШИХ

- **Үнэ:** сүрчиг, гоо сайхны бараа албан ёсны үнээр (`price_source = official`). Бусад барааны ¥ үнэ нь Dewu-ийн **ойролцоо тооцоо** (`estimate`) — Dewu вэбийг програмаар уншиж болдоггүй. Захиалгыг баталгаажуулахаас өмнө Dewu апп дээр бодит үнийг шалгана.
- **Зураг:** бараа бүрт өнгө, төрлөөр нь 3D студийн дүрслэл (`assets/products/*.webp`) үүсгэсэн. Энэ нь жинхэнэ бүтээгдэхүүний зураг биш тул «Жишээ дүрслэл» гэж тэмдэглэгдэнэ.

Бодит болгох 3 арга:

1. **Админ → Бараа:** барааны үнэ, жин, хайрцаг, эх сурвалжийн холбоосыг засаад «Хадгалах». Зураг дээр дарж бодит зураг оруулна.
2. **Админ → Үнэ импорт:** олон барааг нэг дор CSV эсвэл JSON-оор оруулна. Зургийн холбоос өгвөл серверт татаж хадгална. «Бүх барааг CSV-ээр татах» товчоор ID-тай жагсаалт авна.
3. **API:** `POST /api/admin/import` — импортын өгөгдлийг JSON-оор илгээнэ.

Шинэ бараа/брэнд нэмэх: `server/catalog/brands.mjs`, `brands-more.mjs` → `npm run seed` → `npm run render` (зөвхөн шинэ барааны зургийг үүсгэнэ). Гараар оруулсан үнэ, зураг `seed`-ээр устахгүй.

## 4. Захиалга, төлбөр

1. Үйлчлүүлэгч хэмжээгээ сонгож сагсанд хийнэ → **checkout.html** дээр нэр, утас, хаяг бөглөөд «буцаалтгүй» гэдгийг зөвшөөрнө.
2. Сервер үнийг дахин шалгаж захиалга үүсгэнэ (`LV-26-1234`), QPay нэхэмжлэх гаргана.
3. Төлбөр орвол (QPay callback эсвэл «Төлбөр шалгах») төлөв **Төлбөр орсон** болж, Telegram-аар мэдэгдэл ирнэ.
4. Админ → **Захиалга** дээр төлөвийг шилжүүлнэ: Захиалсан → Эрээнд ирсэн → УБ-д ирсэн → Хүргэгдсэн. Захиалга бүрт барааны үнэ, эх сурвалжийн холбоос, хэмжээ харагдана.
5. Үйлчлүүлэгч footer-ийн «Захиалга хянах» хэсэгт дугаараа оруулж бодит төлвийг харна.

## 5. Тохиргоо (`server/.env`)

`server/.env.example`-ийг `server/.env` нэрээр хуулж бөглөнө:

| Түлхүүр | Юунд |
|---|---|
| `ADMIN_TOKEN` | Админ нууц үг (хоосон бол автоматаар үүснэ) |
| `QPAY_CLIENT_ID`, `QPAY_CLIENT_SECRET`, `QPAY_INVOICE_CODE` | QPay мерчант гэрээний дараа. Хоосон бол жишээ QR (demo) |
| `PUBLIC_URL` | Сайтын хаяг — QPay callback-д хэрэгтэй (`https://levera.mn`) |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | Захиалга бүрийн мэдэгдэл утсанд |
| `GEMINI_API_KEY` | AI чат. Хоосон бол бэлэн хариултаар ажиллана |
| Карго тарифын шинэчлэлт | `off` бол тарифыг автоматаар татахгүй |

QPay-ийн код (`server/qpay.mjs`) нь QPay v2 API-ийн дагуу бичигдсэн боловч бодит мерчант эрхгүй тул **туршигдаагүй** — гэрээ хийсний дараа sandbox (`QPAY_BASE=https://merchant-sandbox.qpay.mn`) дээр шалгаарай.

## 7. API

| Арга | Зам | |
|---|---|---|
| GET | `/api/catalog` | Брэнд, бүх бараа (үнэ, карго), тариф |
| GET | `/api/products/:id` | Нэг бараа + үнийн задаргаа |
| POST | `/api/cargo/quote` | `{weight_kg, dims:[l,w,h]}` → Каргоны үнийн санал |

| POST | `/api/orders/:no/check` | QPay төлбөр шалгах |
| POST | `/api/newsletter` | Drop бүртгэл |
| — | `/api/admin/*` | Бараа, зураг, импорт, захиалга, тохиргоо (Bearer token) |

## 8. Байршуулах (deploy)

Энэ нь Node сервер тул **Node ажилладаг VPS / Railway / Render / Fly.io** дээр `npm start`-аар ажиллуулна. `data/` ба `uploads/` фолдерыг байнгын (persistent) диск дээр байлгаарай — database болон зургууд тэнд хадгалагдана.
Зөвхөн статик хостинг (Vercel, Netlify) дээр тавивал сайт `assets/catalog.json`-оос бараагаа харуулна, гэхдээ захиалга, төлбөр, админ ажиллахгүй — тэдгээрт сервер хэрэгтэй (`js/config.js` дотор `LEVERA_API`-д серверийн хаягаа бичнэ).

## 11. Laragon MySQL, бодит зураг, Gemini AI, сэтгэгдэл

### Database — Laragon MySQL
1. Laragon-оо нээгээд **Start All** дарна (MySQL асна).
2. `npm install` → `npm start`. `levera` database, бүх хүснэгт автоматаар үүснэ. Хуучин `data/levera.db` байвал бүх өгөгдлийг (бараа, захиалга, тохиргоо) MySQL руу нэг удаа хуулна.
3. Laragon → **Database** (HeidiSQL) дээрээс `levera` database-ийг шууд харж, засна.

Тохиргоо `server/.env`: `DB_DRIVER=mysql`, `MYSQL_HOST=127.0.0.1`, `MYSQL_PORT=3306`, `MYSQL_USER=root`, `MYSQL_PASSWORD=` (Laragon-д хоосон), `MYSQL_DATABASE=levera`.
MySQL-гүй ажиллуулах бол `DB_DRIVER=sqlite`.

### Барааны бодит зураг
`npm run photos` — бараа бүрийн зургийг вэбээс (Bing зургийн хайлт) хайж, албан ёсны болон итгэмжлэгдсэн дэлгүүрийн зургийг сонгон `uploads/products/`-д 800×1000 хэмжээгээр хадгална. Хуурамч бараа зардаг сайтуудыг (AliExpress, DHgate, Yupoo г.м.) алгасна.
- `npm run photos -- --brand nike` — нэг брэнд, `--id <id> --force` — нэг барааг дахин хайх.
- Хайлтын үр дүн тул заримдаа өнгө, загвар зөрөх боломжтой: **Админ → Бараа** дээр «зураг ↗» холбоосоор эх сурвалжийг шалгаж, буруу бол зураг дээр дарж солино.
- Олдоогүй бараа `data/photo-report.json`-д бичигдэнэ.

### AI туслах (Gemini)
1. https://aistudio.google.com/apikey дээр үнэгүй API key үүсгэнэ.
2. `server/.env` → `GEMINI_API_KEY=...` гэж бичээд серверийг дахин асаана.
Туслах нь бүх хуудсанд («Ask» товч) ажиллана. Серверийн тал database-ээс бараа, үнэ, хэмжээ, үнэлгээг хайж Gemini-д өгдөг тул бодит барааны нэр, үнээр хариулна. Key байхгүй бол бэлэн хариултаар ажиллана.

### Худалдан авагчийн сэтгэгдэл
Барааны хуудас бүрийн доор: дундаж үнэлгээ, одны тархалт, хэмжээ хэр таардаг, сэтгэгдлийн жагсаалт, бичих форм. Захиалгын дугаар + утас оруулбал (төлбөр орсон, тухайн бараа агуулсан захиалга) **«Баталгаат худалдан авалт»** тэмдэг авна. **Админ → Сэтгэгдэл** дээр нууж эсвэл устгана.

### Фонт
Барааны нэр: люкс брэндүүдэд **Cormorant Garamond**, спорт/стрийт брэндүүдэд (Nike, Adidas, Supreme, BAPE, Arc’teryx, Carhartt, Levi’s, Zara г.м.) **Archivo**. Жагсаалт: `server/catalog/build.mjs` → `LUXURY`.

## 12. Шинэчлэлт (2026-10): брэнд, зураг, хямдрал, сэтгэгдэл

### Каталог
36 брэнд, ~1,530 бараа. Шинээр: Nike-ийн KD 1–18, LeBron 1–23, Kobe 1–12 (A.D.), Devin Booker-ийн Book 1–2; Way of Wade, The North Face, Columbia, New Balance, Uniqlo (HEATTECH, sweatpants, hoodie), H&M.
Эх өгөгдөл: `server/catalog/brands-2026.mjs`. Өнгө бүрт StockX-ийн яг нэрийг заасан бол (`sx(...)`) зураг шууд тэр бүтээгдэхүүнээс авагдана.
Шинэ бараа нэмсний дараа: `npm run seed` → `npm run photos`.

### Барааны зураг (бараа бүр 3–5 зурагтай)
| Команд | Юу хийх |
|---|---|
| `npm run photos` | Зураггүй бараанд зураг хайна (StockX → брэндийн албан сайт → итгэмжлэгдсэн дэлгүүр) |
| `npm run photos -- --thin` | 3-аас цөөн зурагтай бараанд нэмж хайна |
| `npm run photos -- --id <id> --replace` | Нэг барааны зургийг шинээр татна |
| `npm run photos:audit` | Бүх зургийг шалгана → `data/photo-audit.json` |
| `npm run photos -- --ids data/photo-audit.json --replace` | Шалгалтад тэнцээгүйг дахин татна |
| `npm run photos:top-up` | 3-аас цөөн зурагтай бараанд өөрийн зургаас ойрын зураг нэмнэ |

Стандарт: цагаан дэвсгэр, бараа бүтэн, голлосон, ижил хэмжээ; гутал — нэг гутал, хажуугаас, хамар нь баруун тийш.
Зургийг гараар солих: Админ → Бараа → зураг дээр дарна (шинэ зураг үндсэн зураг болно).
**Нуусан бараа:** зөв өнгийн/зөв барааны зураг олдоогүй 16 бараа түр нуугдсан — жагсаалт `data/hidden-wrong-photo.json`. Зөв зураг оруулаад «Идэвх»-ийг чагтлахад буцаж гарна.

### Хямдрал (жинхэнэ)
Админ → Бараа: мөр бүрийн «Хямдрал %», эсвэл брэнд/ангилал сонгоод «Хямдрал тавих». Үнэ бодитоор буурна, хуучин үнэ зураастай, «−30%» тэмдэг, цэсний «Хямдрал» хэсэгт харагдана. 0% = хямдрал цуцлах, энгийн үнэ хэвээр хадгалагдана.

### Сэтгэгдэл
Цэс → «Сэтгэгдэл» (`reviews.html`): бүх сэтгэгдэл, брэнд/од/эрэмбээр шүүнэ, сэтгэгдэл бичих форм. Барааны хуудсанд зөвхөн үнэлгээний мөр, тухайн барааны сэтгэгдэл рүү холбоостой.
Жишээ сэтгэгдэл (123, кирилл/латин): `npm run reviews:samples`; устгах: `npm run reviews:clear-samples`. Жишээ нь «Жишээ сэтгэгдэл» тэмдэгтэй, үнэлгээнд тооцогдохгүй.

### Утас
Утсан дээр цэсний товч (☰) толгойн хэсэгт гарна. Барааны зураг дээр дарахад бүтэн дэлгэцээр нээгдэнэ.

### Худалдан авагчийн нэмэлт функц (`js/extras.js`)
- **♡ Хадгалах:** карт болон барааны хуудсан дээр; толгойн ♡ → `saved.html`. Тухайн төхөөрөмжийн хөтчид хадгалагдана.
- **Сүүлд үзсэн:** барааны хуудас, нүүр хуудсанд.
- **Нүүр хуудас:** «Signature цуврал» (KD · LeBron · Kobe · Book, загвар бүрээс нэг) ба «−30°-д бэлэн» өвлийн куртка.
- **Хэмжээний заавар:** гутал (EU/US/UK/см), хувцас, жинс — барааны хуудасны «Хэмжээ»-ний хажууд.
- **Хуваалцах:** утсан дээр утасны хуваалцах цэс, компьютер дээр холбоос хуулна.

### Хэрэглэгчийн бүртгэл (`server/accounts.mjs`, `js/account.js`, `account.html`)
- Утас + нууц үгээр бүртгүүлэх/нэвтрэх (толгойн 👤). Нууц үг scrypt хэшээр хадгалагдана, нэвтрэлт HttpOnly cookie (60 хоног).
- «Миний бүртгэл»: захиалгын түүх, төлөв; хаяг; нууц үг солих; ♡ хадгалсан бараа бүх төхөөрөмж дээр.
- Нэвтэрсэн үед захиалгын маягт өөрөө бөглөгдөж, захиалга бүртгэлд хадгалагдана. SMS баталгаажуулалтгүй тул хуучин захиалгыг утсаар холбодоггүй.
- Нууц үг мартвал: Админ → Хэрэглэгч → «Нууц үг шинэчлэх».

### Админаас шинэ бараа нэмэх
Админ → **+ Шинэ бараа**: шинэ брэнд үүсгэх, зураг (1–8) оруулах. `POST /api/admin/products`, нэмэлт зураг `POST /api/admin/products/:id/photo?append=1`.
